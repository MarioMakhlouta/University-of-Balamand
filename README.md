# **University-of-Balamand**

Welcome to my GitHub repository! This collection includes various academic projects completed during my studies in computer and electrical engineering. Below are brief descriptions of each project, organized by course and topic.

---

## **Projects**

### 1. **Delivery System (CSIS215)**

* **Description**: A delivery management system built using Java and Object-Oriented Programming (OOP) principles. It allows companies to manage orders, deliveries, and schedules efficiently.
* **Technologies Used**: Java, OOP
* **Key Features**:

  * Create, manage, and delete orders
  * Schedule deliveries
  * Track delivery status
* **Folder**: `Delivery System Project`

### 2. **Scientific Calculator (ELEN202)**

* **Description**: A scientific calculator developed using MATLAB to perform complex mathematical calculations such as trigonometric, logarithmic, and exponential functions.
* **Technologies Used**: MATLAB
* **Key Features**:

  * Trigonometric and logarithmic operations
* **Folder**: `Scientific Calculator`

### 3. **Arithmetic Logic Unit (CPEN202)**

* **Description**: This project involves the design and implementation of an Arithmetic Logic Unit (ALU) using Quartus Prime. The ALU can perform operations like addition, subtraction, and set less than (STL).
* **Technologies Used**: Quartus Prime
* **Key Features**:

  * Perform arithmetic (ADD, SUB) and logic (AND, OR, STL) operations
  * Simple design for educational purposes
* **Folder**: `Arithmetic Logic Unit`

### 4. **Temperature Transducer using OP-AMP (ELEN303)**

* **Description**: A temperature transducer circuit using operational amplifiers (OP-AMP) to convert voltage output. The project was simulated in Multisim for accurate analysis and design.
* **Technologies Used**: Multisim, OP-AMP
* **Key Features**:

  * Temperature sensing and conversion
  * Circuit analysis and simulation using Multisim
* **Folder**: `Temperature Transducer`

### 5. **GUI Math Game (CPEN220)**

* **Description**: A Python GUI-based math game that generates random operations (+, -, \*, /). Users earn points for correct answers within a timer. Scores are saved to a file for tracking.
* **Technologies Used**: Python, Tkinter
* **Key Features**:

  * Dynamic random problem generation
  * Scoring system and countdown timer
  * Score saving in a text file (`scores.txt`)
* **Folder**: `GUI Math Game`

### 6. **Parking Gate Controller (CPEN213)**

* **Description**: A microcontroller-based parking gate system designed and implemented using the PIC18 microcontroller, MPLAB IDE, and Proteus for simulation.
* **Technologies Used**: C, MPLAB IDE, Proteus
* **Key Features**:

  * Automatic gate control using sensors
  * Simulation for real-world scenarios
* **Folder**: `Parking Gate Controller`

### 7. **Phone Charger using Diodes (ELEN231)**

* **Description**: A simple phone charger circuit designed with diodes to regulate voltage. The project was simulated and analyzed using Multisim.
* **Technologies Used**: Multisim, Diodes
* **Key Features**:

  * Voltage regulation using diodes
  * Circuit simulation and analysis
* **Folder**: `Phone Charger Using Diodes`

### 8. **Design of a Combinational Lock (CPEN309)**

* **Description**: A combinational lock system designed and simulated using Quartus Prime and implemented on an FPGA. The lock opens upon entering a specific combination sequence.
* **Technologies Used**: Quartus Prime, FPGA
* **Key Features**:

  * Combination sequence recognition
  * Hardware-based logic design and simulation
* **Folder**: `Design of a Combinational Lock`

### 9. **Bitonic Sorting (CPEN313)**

* **Description**: Implementation of a parallel sorter using the Bitonic Sort algorithm in SystemVerilog. Designed to sort unsigned 16-bit numbers on an FPGA with configurable input sizes.
* **Technologies Used**: SystemVerilog, Quartus Prime, FPGA
* **Key Features**:

  * Parallel bitonic sorting for different input sizes
  * Simulation and synthesis for FPGA deployment
* **Folder**: `Bitonic Sorting`

### 10. **Lifeblood Database (CSIS270)**

* **Description**: A database project developed using MariaDB, SQL, and MS Access to manage reports and forms related to blood donations. Includes relational database design and queries.
* **Technologies Used**: MariaDB, SQL, MS Access
* **Key Features**:

  * Relational database design with reports and forms
  * SQL queries and data management
* **Folder**: `Lifeblood Database`
